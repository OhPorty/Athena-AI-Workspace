vLLM unload requires server flags
vLLM only supports unloading a model when its server was launched with VLLM_SERVER_DEV_MODE=1 and --enable-sleep-mode. If this endpoint isn't running with those flags, its model will stay resident in VRAM and can't be freed before another bot on the same machine tries to load -- which can constrain available VRAM.
